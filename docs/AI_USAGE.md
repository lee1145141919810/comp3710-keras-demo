# Statement on the use of AI tools

The COMP3710 demonstration marking scheme permits AI assistance provided that its use is disclosed,
that the student can explain and justify every part of the submitted work, and that evidence of the
interaction (shareable conversation link or exported prompt history) can be produced on request.

## What was used

| Tool | Purpose |
|------|---------|
| Cursor Cloud Agent (Claude) | Drafting the initial implementation of every script in this repository from the lab sheet (v2.01) and the marking rubric, writing docstrings/comments, README and SLURM templates, and running smoke tests on a CPU-only machine. |
| Lab sheet code (COMP3710 teaching team; DFT code generated by them with Gemini 2.5 Pro) | The NumPy square-wave / naive-DFT / eigenfaces snippets in Parts 1-2 are adapted directly from the lab sheet. |

## How the generated code was checked

* Part 1: the torch `square_wave` / `square_wave_fourier` implementations are asserted to match the
  NumPy originals; every DFT variant is compared against `np.fft.fft` (relative error printed).
* Part 2 / 3.1: run end-to-end on the LFW data; accuracies (0.61 random forest, 0.94 CNN) and the
  compactness curve were inspected for plausibility against the scikit-learn example.
* Part 3.2 / Part 4: unit-level checks (`python part3_cnn/dawnbench/resnet.py`,
  `python part4_recognition/vae/model.py`, ...) print parameter counts and output shapes; the training
  scripts were executed with reduced models on a 512-image CIFAR-10 subset and on a synthetic dataset
  that reproduces the `keras_png_slices_data` folder layout and label encoding (0/85/170/255). The
  UNet reached > 0.93 DSC on every synthetic class, confirming that the loss, metrics and one-hot
  handling behave correctly before the real GPU runs.

## Student responsibilities (to complete before the demo)

* Run the GPU parts (3.2, 4.1-4.3) on Rangpur, paste the real numbers/figures into `README.md`, and
  commit them with meaningful messages.
* Export the prompt history / conversation link of the AI sessions used for this project and keep it
  ready (e.g. `docs/prompt_history.pdf`, not committed if it contains personal data).
* Be able to explain every layer, loss term, hyper-parameter and result in your own words - see
  `docs/DEMO_GUIDE_zh.md` for the questions you should expect.
